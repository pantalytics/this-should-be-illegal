# Decisions

Change one only with a pull request that edits this file.

## 1. Small: templates and skills, nothing else

A few good Markdown templates and a few good skills. No platform, no build step, no
integrations we have to maintain.

## 2. Markdown only

No Word, PDF or other formats in the repo. Any AI assistant converts Markdown on request.

## 3. Only real open source and open data

Everything we use or recommend is free to use right away: code under an OSI license, content
under an open license or public domain. No accounts, API keys, download forms or paywalls.

Law text comes from [wetgeving-nl](https://github.com/Apolloccrypt/wetgeving-nl) (NL, CC0)
and [eurlex-mcp-server](https://github.com/Honeyfield-Org/eurlex-mcp-server) (EU, MIT).

## 4. We write every template ourselves, from the statute

No text from commercial or law-firm models, not even as a starting point. Keeps the copyright
clean, so everything stays CC BY 4.0.

## 5. No template? The AI drafts one

The `draft-document` skill writes a missing document from the statute in the same format,
marked `draft`, and offers it back as a contribution.
